# 词条数据

## 武器/工具/弓词条

`/rw affixes` 会列出当前运行时词条。武器词条包括基础属性、吸血、连锁、暴击、状态、协同增伤、爆发/范围、主动/击杀、耐久/工具、弓/弩和契约类词条。

`dash` 不再是武器词条；它是防具词条。

## 词条图鉴

`/rl affixes` 与 `/rw affixes` 打开同一个词条图鉴 GUI，分「武器词条 / 防具词条 / 基础属性」三类，分页浏览。鼠标悬停每个词条图标即可查看具体效果，包括 ID、分类、适用范围、数值示例和机制说明。控制台调用 `/rw affixes` 因无法打开 GUI，仍以聊天列表形式输出。

新增武器词条：

| ID | 名称 | 机制 |
| --- | --- | --- |
| `momentum` | 战意 | 每次命中叠层，每层提升伤害（上限 20 层）；受击或 2 秒未命中清零。高风险高收益，断连即归零。 |
| `crit_lifesteal_percent` | 暴击吸血 | 仅暴击时吸取伤害一定比例的生命，与普通吸血叠加。依赖暴击词条，暴击本身带“受到伤害 200%”副作用。 |
| `crazy_miner` | 疯狂矿工 | 仅镐可获得（`Target.PICKAXE`）；手持时永久急迫 III，挖方块 12% 概率获得 3 tick 饱和；触发后 30 秒冷却，冷却显示在侧边栏。 |

## 与原版附魔重复的处理

保留：`protection`、`thorns`、`swift`。其中 `thorns`/`swift` 是套装自定义语义，不是原版荆棘/迅捷潜行附魔入口。

删除/不进入随机池：`projectile_protection`、`fire_protection`、`feather_falling`、`mending`、`efficiency`、`fortune`。

## 强化显示

- 百分比词条显示为百分比。
- 等级词条显示为等级或数量。
- 契约类词条通常同时给强增益和“受到伤害 200%”副作用。
- 防具套装自带词条在物品 lore 中显示为 `自带词条: 名称 (id)`。
