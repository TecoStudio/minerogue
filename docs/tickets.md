# 券系统

所有券都在铸造台使用：把装备放入铸造台左侧格子，券放入右侧格子，点击成品槽完成加工。详见 [铸造台](forge.md)。

## 强化券 `ticket_a`

打开词条选择 GUI，选择一个可强化词条后按成功率尝试强化。失败消耗券，并为下次普通强化累积 3%-13% 成功率加成。

## 超级强化券 `super_ticket_a`

同样打开强化选择 GUI，但本次强化必定成功。强化量仍按品质区间计算。

## 开发券 `ticket_b`

| 目标 | 效果 |
| --- | --- |
| 普通非 Roguelike 物品 | 开发为 `special_weapon`，保留原物品的材质、显示名称、基础属性与已有攻击距离属性，不使用插件材质包模型 |
| Roguelike 武器、工具 | 随机添加一个尚未拥有且适用于当前材质的武器词条；镐子可获得镐子限定的“疯狂矿工” |
| 防具 | 随机添加一个尚未拥有的可用防具词条 |

## 超级开发券 `super_ticket_b`

仅用于武器和防具，打开词条选择 GUI，玩家可以从当前可用词条中自选一个添加。工具不使用超级开发券。

## 移除券 `ticket_c`

可移除 Roguelike 武器或防具上已记录的插件词条；武器移除还会为下次普通强化成功率 +10%。

## 超级移除券 `super_ticket_c`

仅用于武器和防具，一次移除目标上的全部自选插件词条。不会移除武器模板自带效果或原版附魔；没有可移除词条时不会消耗券。

## 当前防具词条池

```text
dash
thorns
swift
explosive
guardian
vampire
storm
protection
```

套装做出来时会自带对应核心词条；开发券也可能给防具添加可用防具词条。普通“减伤”词条已删除，减伤定位由守护套承担。

## 已删除防具词条

`damage_reduction`（普通减伤）已删除，减伤定位由守护套 `guardian` 承担。
